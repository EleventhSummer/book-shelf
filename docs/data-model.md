# 书单 数据模型（v1）

## 一本书

搜索结果和详情用同一种形状。


| 字段        | 类型              | 接口来源                                           | 没有时       |
| --------- | --------------- | ---------------------------------------------- | --------- |
| `id`      | `string`        | `key` 的最后一段，例如 `/works/OL82563W` 得到 `OL82563W` | 这条结果不放进列表 |
| `title`   | `string`        | `title`                                        | `""`      |
| `authors` | `string[]`      | `author_name`，保持原顺序                            | `[]`      |
| `year`    | `number | null` | `first_publish_year`                           | `null`    |
| `coverId` | `number | null` | `cover_i`                                      | `null`    |


`null` 表示没有，数字表示有值。作者保持数组，显示时再逐个列出。

## 想读清单的一条

想读清单的一条就是上面这一本书。清单类型是 `Book[]`。

- 新加入的书放在数组最前。
- 同一个 `id` 不出现两次。
- 按 `id` 移出。其余书的相对顺序不变。
- 缺的字段沿用上表的空值。

## 搜索状态

- 空关键词：提示「关键词为空，请输入 3–20 字书名或者作者」。列表显示上一次结果。
- 少于 3 个字：提示「至少 3 个字」。列表显示上一次结果。
- 超过 20 个字：提示「不超过 20 个字」。列表显示上一次结果。
- 正在加载：提示「正在加载」。列表显示上一次结果。
- 没有结果：提示「没有结果」。列表为空。
- 请求失败：提示「请求失败」。列表显示上一次结果。
- 有结果：不另外提示。列表换成这次的结果。
- 上面要显示上一次结果、但还没有上一次时，列表为空。



## 两边的边界

接口模块把 `search.json` 里的原始字段转成「一本书」的形状。页面不直接使用 `author_name`、`cover_i`。

存储模块把清单数组存进 `book-shelf:books`。读不到键、内容不是数组、或解析失败时，返回空数组。页面走「清单为空」。
