# 书单

## 目标

在浏览器中搜索书名，打开一本书的详情，把书加入「想读」，数据存在本机。

## 非目标

账号、后端、评分评论、书摘、导入导出、移动端专门适配、UI 组件库。

## 页面与路由

三个页面。顶栏有两个按钮：搜索、想读。

- 搜索：点击「搜索」进入 `/`。页面上方有搜索框。
- 详情：从搜索结果点进去，进入 `/books/:id`。
- 想读：点击「想读」进入 `/want`。

路由 `:id`、判断是不是同一本书、清单里保存的标识，都用搜索结果 `key` 的最后一段。

## 搜索

Open Library 是公开书目数据来源。关键词可以是书名或作者。

合法关键词是去掉首尾空格后的 3–20 个字，中间空格计入。用户按下确认或回车，且关键词合法时，请求：

`https://openlibrary.org/search.json?q=关键词&limit=20`

`q` 使用合法关键词。一次最多 20 条。

不发请求的情况：

- 只输入空格：去掉首尾空格后按空关键词处理，提示关键词为空，请输入 3–20 字书名或者作者。
- 少于 3 个字：提示至少 3 个字。
- 超过 20 个字：提示不超过 20 个字。

新的一次搜索开始后，只采用最后一次请求的结果。更早的请求即使后来返回，也丢弃。

## 搜索状态

- 空关键词：提示关键词为空，请输入 3–20 字书名或者作者。
- 正在加载：提示正在加载。
- 没有结果：提示没有结果，列表为空。
- 请求失败：提示请求失败。

空关键词、少于 3 个字、超过 20 个字、正在加载、请求失败：列表显示上一次结果。没有上一次结果时，列表为空。第一次搜索正在加载，或第一次搜索请求失败，都按没有上一次结果处理。

## 结果字段

搜索列表展示书名 `title`、作者 `author_name`、出版年 `first_publish_year`。

详情展示封面、书名、作者。

想读页只读本机保存的内容，展示书名、作者、出版年。有封面编号才显示封面，没有则封面为空。

搜索列表、详情、想读三处：多个作者按接口顺序全部展示；没有作者则为空。

搜索列表和想读页没有 `first_publish_year` 时，出版年那个位置为空。

## 详情

展示数据只来自刚点开的那条搜索结果。刷新或直接打开 `/books/:id` 时，页面拿不到这条结果，就提示找不到这本书。

封面地址把 `cover_i` 填进 `https://covers.openlibrary.org/b/id/封面编号-M.jpg`。没有 `cover_i` 时，封面区域为空。

## 想读

加入和移出的对象是当前这本书。不允许重复加入。

这本书已经在想读里时，详情上的操作是移出。不在时，操作是加入。想读页可以移出。想读清单的条目不能进入详情。

清单保存 `key` 的最后一段、书名 `title`、作者 `author_name`、出版年 `first_publish_year`、封面编号。缺少的留空。

新加入的书放在清单最前。移出一本后，其余书的相对顺序不变。

清单为空时显示空列表，并有一句可见说明。刷新后数据还在，数据存在本机。
